## 课后思考题  
 - **题一**：一家小规模的私有公司为什么有可能在上个世纪90年代末的时候赶上甚至超过“人类基因组计划”这样一个号称人类三大工程之一的国际项目？  
 *解1*：  
 Celera 采用了全基因组鸟枪法（Whole Genome Shotgun Sequencing），相比人类基因组计划（HGP）采用的分层克隆策略更加激进。私营企业决策链条短、资源集中，因此在效率和速度上具有优势。  
 - **题二**：现有一笼子，里面有鸡和兔子若干只，数一数，共有头14个，腿38条，求鸡和兔子各有多少只？  
 *解2*：  
 - 小学解法：设有x只鸡，y只兔。则：x+y=14，2x+4y=38.联立解得：x=9，y=5。  
 - 中学解法：注意到如果14只全是鸡则有28条腿，差10条，则有5只兔与9只鸡。

## Markdown语言  
  > **[Syntax](https://github.com/adam-p/markdown-here/wiki/Markdown-Cheatsheet)**  
  - `# 标题名`：一个#为最大的一级标题，#越多字号越小，级别越低。
  - `**（文本）**`、`*（文本）*`：两个*围起来为粗体，一个*围起来为斜体。
  - `- 条目名`：分条列举，前为数字时为有序列举。
  - `[链接名](网址)`：超链接。

## 算法(algorithm)和模型(model）的区别：  
  
|  | Algorithm（算法） | Model（模型） |
|---|-----------------|--------------|
| 本质 | 解决问题的计算步骤 | 对现实的抽象描述 |
| 解答的问题 | 如何计算 | 如何描述 |
| 作用 | 解决问题 | 表达规律 |
| 是否依赖数据 | 可以不依赖 | 通常基于数据 |
